# Bijoy Bayanno

Fast, lightweight Bangla typing software for Windows using the government-approved standard layout, with Avro Phonetic support, LAM Mode, and a bulk ANSI-to-Unicode converter.

**Current version:** 16.4.2.0 (Final Release)

---

## ✨ What's New in v16.4.2.0

### 1. Avro Phonetic Support
Type Bangla using English phonetic input, e.g. typing `amar` produces **আমার**, right inside Bijoy Bayanno.

> **Note:** No other official Bijoy software has this feature. It was added entirely by us.

### 2. LAM Mode (Layout Auto-Memory)
Bijoy Bayanno remembers the keyboard layout for each application.

**Example:** You type Bangla in Microsoft Word and English in Notepad. With LAM Mode on, Word stays on Bangla and Notepad stays on English, so you never have to switch manually.

### 3. Fully Customizable Keyboard Shortcuts
In previous versions, the default shortcuts were fixed and could not be changed. Now you have **complete control**: set any shortcut you like for each keyboard layout, directly from **Settings**.

Default shortcuts (all of them can be changed):

| # | Keyboard Mode / Layout | Default Shortcut |
|---|------------------------|------------------|
| 1 | Avro Phonetic          | `Ctrl + Alt + A` |
| 2 | Bijoy Unicode          | `Ctrl + Alt + V` |
| 3 | Bijoy Classic          | `Ctrl + Alt + B` |

> **Tip:** Some shortcuts may clash with Windows or other applications. If a shortcut doesn't work, simply pick a different combination.

### 4. Upgraded Converter: Bulk ANSI → Unicode
The converter has been rebuilt for converting old Bijoy (ANSI) documents to Unicode:

- **Drag & Drop:** drop one or many files straight into the converter
- **Bulk Conversion:** convert multiple files in one go
- **Custom Output Folder:** choose where converted files are saved
- **Formatting Preserved:** document formatting stays intact after conversion

> Other converters are available through the Add-Ins in Microsoft Word.

### 5. Font Management: Clean & Professional
Previous versions installed around 50 fonts into Windows, which cluttered the system Font list and made it hard to find the fonts you actually use. This version installs **only one font family (Sutonny)**, so your system stays free of bloat.

- No more long, confusing font lists in Word and other applications
- Fewer installed files and a lighter footprint on Windows
- Everything you need to type and read Bijoy text, nothing extra

### 6. Splash Screen Removed: Fast as Lightning
The startup splash screen (the welcome image that appeared every time Windows started) has been **removed completely**. Bijoy Bayanno now launches instantly and runs quietly in the background.

- No splash screen delay at startup
- Faster boot and quicker readiness to type

### 7. Modern & Lightweight
A faster, lighter build optimized for modern Windows versions.
